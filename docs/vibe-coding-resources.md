## 4. 詳細（ゲームでの使いやすさ別）

### 4-1. ◎ そのまま使えるもの

#### #14 Kinetics（kinetics.colorion.co）
- **中身**：バネのように弾む動き153種（ボタンの押し込み、通知の飛び出し、数字のカウントアップ、エラー時の揺れ、紙吹雪、タイプライター文字など）。153種すべてに**CSS版**と**AIに渡す用のプロンプト**があり、React版があるのは99種だけ。
- **料金**：無料
- **利用条件**：サイトに「MIT licensed」（自由に使える代表的なライセンス）と表記。ただし正式なライセンス文書のファイルはない。
- **元投稿の説明**：△ 一部不正確。「150以上」は正しい（153種）。「Reactコード付き」は99種のみ。逆に、全種にCSS版がある点（このゲームにとって一番大事な点）は書かれていない。
- **ゲームでの使いどころ**：HPバーが弾んで伸び縮み（Elastic Progress）、被ダメージ時の揺れ（Error Shake）、ゴールド・経験値のカウントアップ（Odometer Count-up）、レベルアップ通知（Toast Overshoot）、勝利時の紙吹雪（Confetti Burst）、物語文のタイプライター表示。一部は「JavaScriptでクラスを付け外しする」前提なので、プロンプト欄も一緒にAIに渡すとよい。
- **確かさ**：高（GitHubのソースで件数を数えて確認）
- **出典**：https://github.com/ckissi/kinetics

#### #24 CSS Text Effects（text-effects.colorion.co）
- **中身**：文字の演出90種（オーロラ、グリッチ＝ノイズ風、空港の案内板風パタパタ、液体が満ちる文字、ネオン、タイプライター、残り火「Emberglow」など）。CSSのみでJavaScript不要。AIに渡す用のプロンプト付き。#14 と同じ作者（Csaba Kissi 氏）。
- **料金**：無料
- **利用条件**：説明文に「MIT licensed」。正式なライセンス文書のファイルはない。
- **元投稿の説明**：説明なし（名前どおりの中身）
- **ゲームでの使いどころ**：タイトル「魔王再臨」に残り火（Emberglow）、クリティカル・大ダメージにグリッチ、ボス名の登場に液体が満ちる演出。
- **注意**：
  - コピーしたCSSの先頭に「--ink」という色の設定が入っています。**ゲームも同じ名前（--ink＝本文の文字色）を使っているため、そのまま貼るとゲーム全体の文字色が変わります。** 名前を変えるようAIに頼んでください。
  - 演出ごとに書体が指定されているので、書体の行は消してもらう（Shippori Mincho B1 を保つため）。
  - タイプライターは半角10文字前提の作りで、長さが変わる日本語の文章には作り直しが必要。
- **確かさ**：高（GitHubのデータで90種を確認）
- **出典**：https://github.com/ckissi/colorion-text-effects

#### #29 Anime.js（animejs.com と推定）
- **中身**：JavaScriptで画面の部品・図形・数値を滑らかに動かす定番ライブラリ（GitHubスター約7.3万）。順番に再生する「タイムライン」、少しずつずらす「スタッガー」、図形の線を描く演出など。最新の正式版は v4.5.0（2026年6月）。
- **料金**：無料（寄付で運営）

- **元投稿の説明**：行の途中で切れていて不明
- **ゲームでの使いどころ**：ダメージ数字がふわっと浮かんで消える、HP/MPバーが滑らかに減る、メニュー項目を順番に出す、魔法陣を線で描く、戦闘の一連の演出をまとめて再生。
- **入れ方**：`<script src="https://cdn.jsdelivr.net/npm/animejs@4.5.0/dist/bundles/anime.umd.min.js"></script>` の1行を足す。オフラインでも動かしたい場合は、このファイル（約118KB。今のゲームファイルの約8%増）を直接埋め込む。
- **注意**：AIは古い書き方（v3）を出すことがあるので「バージョン4.5.0で」と指定する。単純な揺れ程度なら、ゲームに既にあるCSSアニメーションで十分。
- **確かさ**：高（npmの配布データで確認）

## 5. 使うときの共通の注意

素材をゲームに取り入れるときは、AIへの依頼に次の文をそのまま付け足してください。

```
maou.html は React・Tailwind・ビルド作業を使わない、HTMLファイル1つの構成です。
次の素材を、素のHTML／CSS／JavaScriptに書き直して組み込んでください。
- 色は既存のCSS変数（--blood, --blood-bright, --ember, --gold, --ink, --ink-dim）を使う
- 書体は既存（Shippori Mincho B1／Cinzel）を維持し、素材側の書体指定は消す
- クラス名・アニメーション名・CSS変数名には「mo-」を付け、
  既存の .btn / .cta / .ghost、pop / shake / fade、--ink などと重ならないようにする
- スマホにはマウスを乗せる操作がないので、:hover の演出は :active（押したとき）にも付ける
- 素材に入っている作者名・ライセンスのコメントは消さずに残す
- 画像は表示サイズ（64〜128px程度）に縮小してから埋め込む
素材：（ここにURLまたはコードを貼る）
```

### ゲーム用「見た目ルール書（DESIGN.md）」の作り方
#4・#11 で紹介されている形式を真似て、AIに次のように頼むと作れます。作ったファイルをリポジトリに置き、以後の修正依頼のたびに「DESIGN.md に従って」と添えると、見た目がぶれにくくなります。

```
maou.html の <style> を読んで、今の見た目のルールを DESIGN.md にまとめてください。
色（CSS変数）、書体の使い分け、文字サイズ、余白、角丸、ボタン（.btn / .cta / .ghost）、
ゲージ（HP/MP/XP）、ポップアップ（#modal / .sheet）、アニメーション（@keyframes）、
画面幅（最大560px・スマホ縦画面）を含めてください。新しいルールは作らず、今の実装から読み取れることだけを書いてください。
```
